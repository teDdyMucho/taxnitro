## What shipped today

### 1. Client tailoring (BK / CFO / QBO)
- **Client type on account creation** — Add Client modal now asks Bookkeeping / CFO (one or both), saved to a new `services[]` column on profiles. Editable later in Manage Client (BK→CFO upgrade).
- **QBO access question** — "Do we already have QBO access?" (shown when CFO selected). When yes, "Prior Month Bookkeeping / QBO Access" is dropped from that client's required docs (`has_qbo_access` + `itemsForClient()` filter).
- **Category visibility by service** — a BK-only client sees only Bookkeeping; CFO-only sees only CFO; both sees both. Requirement checklists + progress denominators are now per-client.

### 2. Tax → CFO rename
- The "Tax Documents & Returns" category card is now **CFO** (label/description/abbr). Internal keys (`tax_*` tables) unchanged.

### 3. Per-document chat (brought back)
- `FileConversationPanel` — shared client↔staff notes on a specific document. Reachable from the client doc detail ("Message Admin" / "Reply to Feedback") and the admin file browser. Backed by `file_conversations`.

### 4. Client approve/reject of staff-delivered files
- Staff can now **Send File** into a client's folder (new flow in admin client view), tagged `uploaded_by_role='staff'`.
- The client sees a **Review This File** card (Approve / Reject) — only on staff-delivered pending files.

### 5. Custom document requests (staff → client)
- **Request Doc** in the admin client view creates a one-off request for the month.
- Client dashboard shows them under **Special Requests** (grey → In review → Accepted/Declined).

### 6. Responsive modals
- Bottom-sheet modals now become **centered, width-capped dialogs on desktop** (≥1024px) while staying bottom sheets on phone. Applied to Add Client, Manage Client, Progress Detail, Add Staff, Send File, Request Doc, Create Workflow, and the doc action menu.
- **Screens stay full-width** (per your feedback — "buo dapat"); only modals center. Full-screen viewers/chat/file-browser stay full-screen (your call).
- New infra: `useResponsive` hook, `useSheetStyles` hook, `constants/layout.ts` breakpoint tokens, `ResponsiveContainer`.

## Bugs fixed

| Bug | Cause | Fix |
|-----|-------|-----|
| **Whole admin app 500s** — "infinite recursion in policy for profiles" | A profiles RLS policy sub-selected `profiles` inside itself | `is_staff_or_admin()` SECURITY DEFINER function; all policies routed through it |
| **Migration re-run error** — "policy already exists" | A renamed policy dropped only its old name | Added drop-if-exists for the new name; audited all migrations for re-runnability |
| **Can't delete files** — "0 rows deleted (blocked by RLS)" | Older folder tables (`tax_client_uploads`, `*_contracts`, etc.) had no DELETE policy | `folder_delete_policies.sql` adds client + staff/admin DELETE to all 10 folder tables |
| **Silent fake-delete** | `deleteDocument` returned true even when 0 rows deleted | Now verifies rows deleted; surfaces a real error to the user |
