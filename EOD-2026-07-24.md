## What shipped today

### 1. Three-way client service model (BK / TAX / CFO)
- Client Type is now **three separate checkboxes** — Bookkeeping, TAX, CFO — pickable in any combination on Add Client and editable in Manage Client.
- Each service reveals its own category on the client side; a client only sees a category if the admin checked that box.
- Repointed the existing **TAX card** from the old `CFO` service to its own `TAX` service (they were sharing before).
- Data model updated across the board: `ClientService`/`RequirementService` types, `AuthContext`, and the profiles `services[]` CHECK constraint now allow `BK`/`TAX`/`CFO`.

### 2. New CFO Advisory category (with nested folders)
- New third category card **CFO Advisory** with 6 folders:
  - CFO Contracts · CFO Invoices · Additional CFO Docs
  - **Monthly Reporting** (a group folder you tap INTO):
    - Required Info · For Client Review · Final Statements & Insights
- Added the app's first **3rd navigation level** — group folders open a nested folder list, with correct back navigation and doc counts (a group sums its children).
- 6 new Supabase tables with full RLS (client view/insert/update/delete own, staff/admin manage all) + uploader tracking.
- Registered everywhere: `FOLDER_TABLES`, admin dashboard meta, documents filter, reply-bell labels, file browser, staff "Send File" folders.

### 3. Admin dashboard — segregated folder breakdown
- "Documents by Folder" is no longer one flat list. It's now **one card per category** (Tax / Bookkeeping / CFO), each with a header (icon + name + folder count), a category total badge, and the folder rows underneath. Empty categories auto-hide.

### 4. Admin Documents — scrollable filter chips
- With the new CFO folders the filter chip row overflowed off-screen. It's now **horizontally scrollable**, including **mouse-wheel → horizontal scroll** and a visible scrollbar on web so a normal mouse can reach every chip.

### 5. Responsive modals (finished)
- Bottom-sheet modals become **centered, width-capped dialogs on desktop** (≥1024px) and stay bottom sheets on phone. Screens themselves stay full-width; only modals center. Applied across all admin sheets.

### 6. TAX/CFO label cleanup
- Earlier in the day: relabeled the old "CFO" display strings back to "TAX" (category card, client-type toggle, checklist group headers) before the three-way split made them properly distinct.
