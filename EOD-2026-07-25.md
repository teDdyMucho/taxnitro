## What shipped today

### 1. "Required Documents" folder removed → individual item folders
- The old `tax_required_documents` / `bk_required_documents` folders (with the in-folder item picker) are gone.
- Each required item is now its **own folder** with its own table:
  - **TAX**: Prior Month Bookkeeping / QBO Access, AR / AP Aging
  - **BK**: Bank Statements, Credit Card Statements, Loan Statements, Payroll Reports
- **Progress tracking preserved** — uploading into an item folder auto-tags the requirement (dashboard radios still go grey → yellow → green; approve/reject/delete still work, keyed by the doc's folder).
- The upload picker step is removed — the folder *is* the item now.

### 2. Folder arrangement + label changes
- **TAX order**: Client Uploads, Additional Tax Docs, Tax Contracts, Tax Invoices, Tax Returns, then the 2 required items at the end.
- **BK order**: BK Contracts, BK Invoices, **Additional BK Docs** (renamed from "Final P&L", reuses `bk_final_pnl`), Monthly Reporting ×3, For Client Review, then the 4 required items at the end.
- **CFO**: "Monthly Reporting (Final Statements)" → **"Monthly Reporting (Final Statements & Insights)"**.
- All labels propagated across admin dashboard, documents filter, reply-bell, file browser, and staff "Send File".

### 3. Financial Reports tab (staff + admin)
- New nav item **"Financial Reports"** that opens the FTG Financial Report Generator (a 680KB self-contained HTML tool) in a **new browser tab**. Served as a static asset (`public/financial-report.html`).
- Visible to both staff and admin (it lives in the admin navigator).

### 4. Admin Documents — per-folder dropdown filter
- Replaced the long horizontal chip row with a clean **dropdown** grouped by category (Quick / Tax / Bookkeeping / CFO). Centered dialog on desktop, bottom sheet on phone.

### 5. Admin dashboard — collapsible Monthly Reporting
- The three "Monthly Reporting (…)" rows collapse into **one expandable "Monthly Reporting" parent** per category (BK, CFO), showing the combined total. Tap to reveal the 3 subfolders with their real counts. Subfolder labels show only the inner part (Required Info / For Client Review / Final Statements). Bar-chart icon on the parent.

### 6. Role-aware admin greeting
- The admin dashboard header now shows the logged-in person's first name; staff see "Staff Portal · Finance Therapy Group" instead of the hardcoded "Admin".
